OpenBitFun 1.0.12 桌面端更新

- 对话里可以直接查看图表和交互式可视化。图表随聊天主题切换，桌面安装包内置了离线渲染所需的资源。
- Ask 模式减少了普通工作区编辑和安全只读命令的确认弹窗。删除文件、访问敏感路径和发布操作仍需审批。升级提醒：如果曾用 `custom_tool` 为内置工具设置规则或授权，请在权限设置中按对应操作重新配置，旧规则不会自动迁移。
- 在聊天输入框输入 `/model` 即可打开模型选择器。使用 Responses API 的模型可选择 WebSocket 传输和增量上下文；Gemini 对工具参数的兼容性也有所改善。
- 远程连接支持按设备关闭入站控制。跨设备会话中的 `/btw` 追问支持流式回复和历史回放。通过 SSH 派发任务时，需先在目标机器安装 OpenBitFun，再检查目标是否可用。
- 视觉皮肤支持 MP4 背景，可从设置中进入皮肤设计或停用当前皮肤。改善滚动聊天记录时的渲染性能，以及全局搜索连续输入时的响应速度。
- 修复定时任务重启后丢失待执行触发的问题，改善长时间生成的洞察报告及其导出语言。Windows 可拖动标题栏还原最大化窗口，Linux 桌面包修复了托盘运行库的兼容问题。
